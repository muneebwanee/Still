# Connect in three steps

Version 1.2 · Effective November 10, 2026

## 1. Start on this screen

Connect your iPhone or iPad to Wi-Fi. Open Still and tap Start receiver. Allow Local Network access if iOS asks. Keep Still open.

## 2. Scan from the other device

Put your other phone, tablet or computer on the same Wi-Fi. Scan Still’s QR code using that device’s camera. If scanning is difficult, use Share pairing link or expand Can’t scan the code? to copy the complete link.

## 3. Send a video

In YouTube, choose Share → Copy link. Open the paired browser remote, paste the link and press Play now. Direct HTTPS media links work too. Add to queue keeps the current video playing. If queue-only mode is on, remotes can add videos while playback remains under this screen’s control.

## If it will not connect

Keep Still open and check that both devices use the same Wi-Fi. In iOS Settings → Privacy & Security → Local Network, allow Still. Guest networks, VPNs, captive portals, browser HTTPS-only settings and router isolation can block local pairing. Start again after a Wi-Fi change and scan the new code. Local pairing uses HTTP, so use trusted Wi-Fi.

## If a video will not play

Try another video to distinguish a bad source from a connection issue. YouTube videos may block embedding, require sign-in or need a tap on the receiver’s player. Use Open original when available. Streams need supported codecs, valid HTTPS certificates and an unexpired URL. Check that YouTube playback has not been turned off in Privacy & Data.

## Keep it simple

The everyday flow is Start → Scan → Play. Settings is optional. Try a sleep timer for bedtime or queue-only remotes when friends are choosing videos. Stop receiver ends remote access. Wipe local data resets the app when you want to start fresh.
